# Proveniência

A aplicação web adapta o modelo Python `Agri-SECA-Kcb-mensal-v0.1.zip`, desenvolvido a partir do núcleo físico `agri-seca-robustez-fisica.zip` de setembro de 2026. A tradução JavaScript mantém as equações e a ordem de operações no domínio restrito de raízes fixas, perfil homogéneo e dois compartimentos de profundidade.

A interface e o motor JavaScript são código fonte fornecido ao utilizador sob GPL-3.0-or-later, preservando a licença do modelo antecedente. O ficheiro LICENSE contém o texto da licença. Não se incluem dependências de terceiros, fontes externas ou mapas comerciais.

`METODOLOGIA.md` conserva a especificação da versão Python para consulta das hipóteses físicas. As entradas, formatos de referência e comandos específicos da interface web são descritos no README desta aplicação. Os nomes de compatibilidade de fluxos descritos no documento Python não são todos exportados pela versão web.

A demonstração é sintética e a verificação contra Python é numérica. Nenhuma dessas verificações estabelece validação agronómica, endosso da FAO ou superioridade relativamente a outros índices de seca.
